# cluster analysis

## definitions

Typical cluster models include:

- connectivity models ::@:: For example, the [hierarchical clustering](hierarchical%20clustering.md) builds or divides into clusters based on distance connectivity. <!--SR:!2028-11-18,1226,310!2028-11-11,1301,350-->
- centroid models ::@:: For example, the [k-means clustering](k-means%20clustering.md) represents each cluster by its mean vector. <!--SR:!fsrs,2032-09-24T00:00:00.000Z,2225,2224.72852964,1,2,10,0,0,2026-08-22T00:00:00.000Z!2028-04-28,1148,350-->
