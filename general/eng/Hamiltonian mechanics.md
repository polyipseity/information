In {@{[physics](physics.md)}@}, {@{__Hamiltonian mechanics__}@} is {@{a reformulation of [Lagrangian mechanics](Lagrangian%20mechanics.md) that emerged in 1833}@}. Introduced by {@{[Sir William Rowan Hamilton](Sir%20William%20Rowan%20Hamilton.md)}@},<sup>[\[1\]](#^ref-1)</sup> {@{Hamiltonian mechanics}@} replaces {@{\(generalized\) velocities ${\dot {q} }^{i}$ used in Lagrangian mechanics with \(generalized\) _momenta_}@}. {@{Both theories}@} provide {@{interpretations of [classical mechanics](classical%20mechanics.md)}@} and describe {@{the same physical phenomena}@}.

{@{Hamiltonian mechanics}@} has {@{a close relationship with geometry}@} \(notably, {@{[symplectic geometry](symplectic%20geometry.md) and [Poisson structures](Poisson%20structure.md)}@}\) and serves as {@{a [link](Hamilton–Jacobi%20equation.md) between classical and [quantum mechanics](quantum%20mechanics.md)}@}.

## overview

### phase space coordinates \(_p_, _q_\) and Hamiltonian _H_

Let {@{$(M,{\mathcal {L} })$ be a [mechanical system](Lagrangian%20mechanics.md)}@} with {@{[configuration space](configuration%20space%20(physics).md) $M$ and smooth [Lagrangian](Lagrangian%20mechanics.md#Lagrangian) ${\mathcal {L} }$}@}. Select {@{a standard coordinate system $({\boldsymbol {q} },{\boldsymbol {\dot {q} } })$}@} on {@{the [tangent bundle](tangent%20bundle.md) $TM$}@}. {@{The quantities $\textstyle p_{i}({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)~{\stackrel {\text{def} }{=} }~{\partial {\mathcal {L} } }/{\partial {\dot {q} }^{i} }$}@} are called {@{_momenta_. \(Also _generalized momenta_, _conjugate momenta_, and _canonical momenta_\)}@}. For {@{a time instant $t$}@}, {@{the [Legendre transformation](Legendre%20transformation.md#Legendre%20transformation%20on%20manifolds) of ${\mathcal {L} }$}@} is defined as {@{the map $({\boldsymbol {q} },{\boldsymbol {\dot {q} } })\to \left({\boldsymbol {p} },{\boldsymbol {q} }\right)$}@} which is assumed to have {@{a smooth inverse $({\boldsymbol {p} },{\boldsymbol {q} })\to ({\boldsymbol {q} },{\boldsymbol {\dot {q} } })$}@}. For {@{a system with $n$ degrees of freedom}@}, the Lagrangian mechanics defines {@{the _energy function_}@} {@{$$E_{\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)\,{\stackrel {\text{def} }{=} }\,\sum _{i=1}^{n}{\dot {q} }^{i}{\frac {\partial {\mathcal {L} } }{\partial {\dot {q} }^{i} } }-{\mathcal {L} }.$$}@}

{@{The Legendre transform of ${\mathcal {L} }$}@} turns {@{$E_{\mathcal {L} }$ into a function ${\mathcal {H} }({\boldsymbol {p} },{\boldsymbol {q} },t)$}@} known as {@{the __Hamiltonian__}@}. {@{The Hamiltonian}@} satisfies {@{$${\mathcal {H} }{\left({\frac {\partial {\mathcal {L} } }{\partial {\boldsymbol {\dot {q} } } } },{\boldsymbol {q} },t\right)}=E_{\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)$$}@} which implies that {@{$${\mathcal {H} }({\boldsymbol {p} },{\boldsymbol {q} },t)=\sum _{i=1}^{n}p_{i}{\dot {q} }^{i}-{\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t),$$}@} where {@{the velocities ${\boldsymbol {\dot {q} } }=({\dot {q} }^{1},\ldots ,{\dot {q} }^{n})$}@} are found from {@{the \($n$-dimensional\) equation $\textstyle {\boldsymbol {p} }={\partial {\mathcal {L} } }/{\partial {\boldsymbol {\dot {q} } } }$}@} which, by {@{assumption, is uniquely solvable for ⁠${\boldsymbol {\dot {q} } }$⁠}@}. {@{The \($2n$-dimensional\) pair $({\boldsymbol {p} },{\boldsymbol {q} })$}@} is called {@{_phase space coordinates_. \(Also _canonical coordinates_\)}@}.

### from Euler–Lagrange equation to Hamilton's equations

In {@{phase space coordinates ⁠$({\boldsymbol {p} },{\boldsymbol {q} })$}@}⁠, {@{the \($n$-dimensional\) [Euler–Lagrange equation](Euler–Lagrange%20equation.md)}@} {@{$${\frac {\partial {\mathcal {L} } }{\partial {\boldsymbol {q} } } }-{\frac {d}{dt} }{\frac {\partial {\mathcal {L} } }{\partial {\dot {\boldsymbol {q} } } } }=0$$}@} becomes {@{_Hamilton's equations_ in $2n$ dimensions}@}

> (annotation: {@{Hamilton's equations in $2n$ dimensions}@})
>
> {@{$${\frac {\mathrm {d} {\boldsymbol {q} } }{\mathrm {d} t} }={\frac {\partial {\mathcal {H} } }{\partial {\boldsymbol {p} } } },\quad {\frac {\mathrm {d} {\boldsymbol {p} } }{\mathrm {d} t} }=-{\frac {\partial {\mathcal {H} } }{\partial {\boldsymbol {q} } } }.$$}@}
>
> (annotation: Using {@{a non-rigorous intuitive interpretation}@} here. {@{Speed ($\dot{\mathbf q}$)}@} is how {@{kinetic energy ($\frac{p^2}{2m}$) scales with momentum}@}, which yields {@{classic velocity ($\frac{p}{m}$)}@}. {@{Force ($\dot{\mathbf p}$)}@} is {@{the negative slope of potential energy}@}, which {@{accelerates momentum downhill toward lower energy}@}.)

> | {@{$${\mathcal {L} }({\boldsymbol {q} },{\dot {\boldsymbol {q} } })+{\mathcal {H} }({\boldsymbol {p} },{\boldsymbol {q} })={\boldsymbol {p} }{\dot {\boldsymbol {q} } }$$}@} | <a id="math_1"></a> __\(1\)__ |
>
> where {@{${\boldsymbol {p} }=\partial {\mathcal {L} }/\partial {\dot {\boldsymbol {q} } }$}@}.

>

>
> Now {@{the Euler–Lagrange equations}@} yield {@{${\dot {\boldsymbol {p} } }={\frac {\mathrm {d} }{\mathrm {d} t} }{\frac {\partial {\mathcal {L} } }{\partial {\dot {\boldsymbol {q} } } } }={\frac {\partial {\mathcal {L} } }{\partial {\boldsymbol {q} } } }=-{\frac {\partial {\mathcal {H} } }{\partial {\boldsymbol {q} } } }$}@}.

### from stationary action principle to Hamilton's equations

Let {@{${\mathcal {P} }(a,b,{\boldsymbol {x} }_{a},{\boldsymbol {x} }_{b})$}@} be {@{the set of smooth paths ${\boldsymbol {q} }:[a,b]\to M$ for which ${\boldsymbol {q} }(a)={\boldsymbol {x} }_{a}$ and ${\boldsymbol {q} }(b)={\boldsymbol {x} }_{b}$}@}. {@{The [action functional](action%20(physics).md) ${\mathcal {S} }:{\mathcal {P} }(a,b,{\boldsymbol {x} }_{a},{\boldsymbol {x} }_{b})\to \mathbb {R}$}@} is defined via {@{$${\mathcal {S} }[{\boldsymbol {q} }]=\int _{a}^{b}{\mathcal {L} }(t,{\boldsymbol {q} }(t),{\dot {\boldsymbol {q} } }(t))\,dt=\int _{a}^{b}\left(\sum _{i=1}^{n}p_{i}{\dot {q} }^{i}-{\mathcal {H} }({\boldsymbol {p} },{\boldsymbol {q} },t)\right)\,dt,$$}@} where {@{⁠${\boldsymbol {q} }={\boldsymbol {q} }(t)$⁠, and ${\boldsymbol {p} }=\partial {\mathcal {L} }/\partial {\boldsymbol {\dot {q} } }$ \(see above\)}@}. {@{A path ${\boldsymbol {q} }\in {\mathcal {P} }(a,b,{\boldsymbol {x} }_{a},{\boldsymbol {x} }_{b})$}@} is {@{a [stationary point](Lagrangian%20mechanics.md) of ${\mathcal {S} }$ \(and hence is an equation of motion\)}@} {@{if and only if the path $({\boldsymbol {p} }(t),{\boldsymbol {q} }(t))$ in phase space coordinates obeys the Hamilton equations}@}.

### basic physical interpretation

{@{A simple interpretation}@} of Hamiltonian mechanics comes from its {@{application on a one-dimensional system consisting of one nonrelativistic particle of mass _m_}@}. {@{The value $H(p,q)$ of the Hamiltonian}@} is {@{the total energy of the system}@}, in this case {@{the sum of [kinetic](kinetic%20energy.md) and [potential energy](potential%20energy.md)}@}, traditionally denoted {@{_T_ and _V_, respectively}@}. Here _p_ is {@{the momentum _mv_ and _q_ is the space coordinate}@}. Then {@{$${\mathcal {H} }=T+V,\qquad T={\frac {p^{2} }{2m} },\qquad V=V(q)$$}@} _T_ is {@{a function of _p_ alone}@}, while _V_ is {@{a function of _q_ alone}@} \(i.e., {@{_T_ and _V_ are [scleronomic](scleronomic.md)}@}\).

In this example, {@{the time derivative of _q_}@} is {@{the velocity}@}, and so {@{the first Hamilton equation}@} means that {@{the particle's velocity equals the derivative of its kinetic energy with respect to its momentum}@}. {@{The time derivative of the momentum _p_}@} equals {@{the _Newtonian force_}@}, and so {@{the second Hamilton equation}@} means that {@{the force equals the negative [gradient](gradient.md) of potential energy}@}.

## example

- Main article: ::@:: [Spherical pendulum](spherical%20pendulum.md)

(annotation: {@{Partial differentiation}@} of {@{the Hamiltonian $H$ with respect to any phase-space variable}@} requires holding all {@{remaining canonical variables in $(p, q, t)$ strictly constant}@}. {@{This error frequently arises}@} when transitioning {@{from the Lagrangian framework}@} or retaining {@{generalized velocities $\dot{q}$ within $H$ prior to taking derivatives}@}. To prevent this, completely {@{invert the momentum mapping $p(q, \dot{q})$}@} to express $H$ {@{strictly in terms of canonical variables $(p, q, t)$ before evaluating derivatives}@}, eliminating {@{all generalized velocities $\dot{q}$}@}. Alternatively, if {@{velocity terms are retained}@}, explicitly apply {@{the multivariable chain rule}@} to capture their {@{implicit variation under fixed canonical momenta}@}.)

{@{A spherical pendulum}@} consists of {@{a [mass](mass.md) _m_ moving without [friction](friction.md) on the surface of a [sphere](sphere.md)}@}. {@{The only [forces](force.md) acting on the mass}@} are {@{the [reaction](reaction%20(physics).md) from the sphere and [gravity](gravity.md)}@}. {@{[Spherical coordinates](spherical%20coordinates.md)}@} are used to describe {@{the position of the mass in terms of \(_r_, _θ_, _φ_\)}@}, where {@{_r_ is fixed, _r_ = _ℓ_}@}.

> {@{![Spherical pendulum angles and velocities.](../../archives/Wikimedia%20Commons/Spherical%20pendulum%20Lagrangian%20mechanics.svg)}@}
>
> {@{[Spherical pendulum](spherical%20pendulum.md)}@}: {@{angles and velocities}@}.

{@{The Lagrangian for this system}@} is<sup>[\[2\]](#^ref-2)</sup> {@{$$L={\frac {1}{2} }m\ell ^{2}\left({\dot {\theta } }^{2}+\sin ^{2}\theta \ {\dot {\varphi } }^{2}\right)+mg\ell \cos \theta .$$}@} (annotation: Recall in this case, the Lagrangian is {@{$L = T - V$}@}. For the kinetic energy $T$, recall {@{the metric tensor in spherical coordinates: $g = \operatorname{diag}(1, \theta^2, \sin^2\theta)$}@}. For the potential energy $V$, recall {@{$mgh$}@}.)

Thus {@{the Hamiltonian}@} is {@{$$H=P_{\theta }{\dot {\theta } }+P_{\varphi }{\dot {\varphi } }-L$$ (annotation: by definition)}@} where {@{$$P_{\theta }={\frac {\partial L}{\partial {\dot {\theta } } } }=m\ell ^{2}{\dot {\theta } }$$}@} and {@{$$P_{\varphi }={\frac {\partial L}{\partial {\dot {\varphi } } } }=m\ell ^{2}\sin ^{2}\!\theta \,{\dot {\varphi } }.$$}@} In terms of {@{coordinates and momenta, the Hamiltonian}@} reads {@{$${\begin{aligned}H&=\underbrace { {\Bigl [}{\tfrac {1}{2} }m\ell ^{2}{\dot {\theta } }^{2}+{\tfrac {1}{2} }m\ell ^{2}\sin ^{2}\!\theta \,{\dot {\varphi } }^{2}{\Bigr ]} } _{T}+\underbrace { {\Bigl [}-mg\ell \cos \theta {\Bigr ]} } _{V}\\[2ex]&={\frac {P_{\theta }^{2} }{2m\ell ^{2} } }+{\frac {P_{\varphi }^{2} }{2m\ell ^{2}\sin ^{2}\theta } }-mg\ell \cos \theta .\end{aligned} }$$}@} (annotation: It might seem {@{pointless to rewrite the Hamiltonian in terms of coordinates and momenta}@} in the last line. It is required to ensure {@{the partial derivatives are taken correctly}@}, as partial derivatives {@{assume other inputs are fixed}@}. Not rewriting means we assume {@{the wrong inputs are fixed}@}.) {@{Hamilton's equations}@} give {@{the time evolution of coordinates and conjugate momenta}@} in {@{four first-order differential equations}@}, {@{$${\begin{aligned}{\dot {\theta } }&={P_{\theta } \over m\ell ^{2} }\\[6pt]{\dot {\varphi } }&={P_{\varphi } \over m\ell ^{2}\sin ^{2}\theta }\\[6pt]{\dot {P_{\theta } } }&={P_{\varphi }^{2} \over m\ell ^{2}\sin ^{3}\theta }\cos \theta -mg\ell \sin \theta \\[6pt]{\dot {P_{\varphi } } }&=0.\end{aligned} }$$}@} (annotation: As mentioned above, it is important that you differentiate {@{using the Hamiltonian in terms of coordinates and momenta only}@}, otherwise here you will get {@{the wrong expression for $\dot P_\theta = -\frac {\partial H(\mathbf p, \mathbf q)} {\partial \dot \theta} \ne -\frac {\partial H(\mathbf q, \dot{\mathbf q})} {\partial \dot \theta}$}@}.) {@{Momentum ⁠$P_{\varphi }$}@}⁠, which corresponds to {@{the vertical component of [angular momentum](angular%20momentum.md) ⁠$L_{z}=\ell \sin \theta \times m\ell \sin \theta \,{\dot {\varphi } }$}@}⁠, is {@{a constant of motion}@}. That is a {@{consequence of the rotational symmetry of the system around the vertical axis}@}. Being {@{absent from the Hamiltonian}@}, {@{[azimuth](azimuth.md) $\varphi$ is a [cyclic coordinate](cyclic%20coordinate.md)}@}, which implies {@{conservation of its conjugate momentum}@}.

## deriving Hamilton's equations

{@{Hamilton's equations can be derived}@} by {@{a calculation with the [Lagrangian](Lagrangian%20mechanics.md) ⁠${\mathcal {L} }$}@}⁠, {@{generalized positions _q<sup>i</sup>_, and generalized velocities $\frac{}{}$<sup>_i_</sup>, where ⁠$i=1,\ldots ,n$⁠}@}.<sup>[\[3\]](#^ref-3)</sup> Here we work {@{[off-shell](on%20shell%20and%20off%20shell.md)}@}, meaning {@{⁠$q^{i}$⁠, ⁠${\dot {q} }^{i}$⁠, ⁠$t$⁠ are independent coordinates in phase space}@}, not {@{constrained to follow any equations of motion}@} \(in particular, {@{${\dot {q} }^{i}$ is not a derivative of ⁠$q^{i}$}@}⁠\). {@{The [total differential](total%20differential.md#differentials%20in%20several%20variables) of the Lagrangian}@} is: {@{$$\mathrm {d} {\mathcal {L} }=\sum _{i}\left({\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\mathrm {d} q^{i}+{\frac {\partial {\mathcal {L} } }{\partial {\dot {q} }^{i} } }\,\mathrm {d} {\dot {q} }^{i}\right)+{\frac {\partial {\mathcal {L} } }{\partial t} }\,\mathrm {d} t\ .$$}@} {@{The generalized momentum coordinates}@} were defined as {@{⁠$p_{i}=\partial {\mathcal {L} }/\partial {\dot {q} }^{i}$}@}⁠, so we may {@{rewrite the equation}@} as: {@{$${\begin{aligned}\mathrm {d} {\mathcal {L} }=&\sum _{i}\left({\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\,\mathrm {d} q^{i}+p_{i}\mathrm {d} {\dot {q} }^{i}\right)+{\frac {\partial {\mathcal {L} } }{\partial t} }\mathrm {d} t\\=&\sum _{i}\left({\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\,\mathrm {d} q^{i}+\mathrm {d} (p_{i}{\dot {q} }^{i})-{\dot {q} }^{i}\,\mathrm {d} p_{i}\right)+{\frac {\partial {\mathcal {L} } }{\partial t} }\,\mathrm {d} t\,.\end{aligned} }$$}@} (annotation: Reminds one of {@{integration by part}@}.) After {@{rearranging, one obtains}@}: {@{$$\mathrm {d} \!\left(\sum _{i}p_{i}{\dot {q} }^{i}-{\mathcal {L} }\right)=\sum _{i}\left(-{\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\,\mathrm {d} q^{i}+{\dot {q} }^{i}\mathrm {d} p_{i}\right)-{\frac {\partial {\mathcal {L} } }{\partial t} }\,\mathrm {d} t\ .$$}@}

{@{The term in parentheses on the left-hand side}@} is just {@{the Hamiltonian ${\mathcal {H} }=\sum p_{i}{\dot {q} }^{i}-{\mathcal {L} }$ defined previously}@}, therefore: {@{$$\mathrm {d} {\mathcal {H} }=\sum _{i}\left(-{\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\,\mathrm {d} q^{i}+{\dot {q} }^{i}\,\mathrm {d} p_{i}\right)-{\frac {\partial {\mathcal {L} } }{\partial t} }\,\mathrm {d} t\ .$$}@} One may also calculate {@{the total differential of the Hamiltonian ${\mathcal {H} }$}@} with respect to {@{coordinates ⁠$q^{i}$⁠, ⁠$p_{i}$⁠, ⁠$t$⁠ instead of ⁠$q^{i}$⁠, ⁠${\dot {q} }^{i}$⁠, ⁠$t$}@}⁠, yielding: {@{$$\mathrm {d} {\mathcal {H} }=\sum _{i}\left({\frac {\partial {\mathcal {H} } }{\partial q^{i} } }\mathrm {d} q^{i}+{\frac {\partial {\mathcal {H} } }{\partial p_{i} } }\mathrm {d} p_{i}\right)+{\frac {\partial {\mathcal {H} } }{\partial t} }\,\mathrm {d} t\ .$$}@} One may now equate {@{these two expressions for ⁠$d{\mathcal {H} }$⁠}@}, one {@{in terms of ⁠${\mathcal {L} }$⁠, the other in terms of ⁠${\mathcal {H} }$}@}⁠: {@{$$\sum _{i}\left(-{\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\mathrm {d} q^{i}+{\dot {q} }^{i}\mathrm {d} p_{i}\right)-{\frac {\partial {\mathcal {L} } }{\partial t} }\,\mathrm {d} t\ =\ \sum _{i}\left({\frac {\partial {\mathcal {H} } }{\partial q^{i} } }\mathrm {d} q^{i}+{\frac {\partial {\mathcal {H} } }{\partial p_{i} } }\mathrm {d} p_{i}\right)+{\frac {\partial {\mathcal {H} } }{\partial t} }\,\mathrm {d} t\ .$$}@}

Since {@{these calculations are off-shell (annotation: in particular, the positions and the velocities are unrelated)}@}, one can equate {@{the respective coefficients of ⁠$\mathrm {d} q^{i}$⁠, ⁠$\mathrm {d} p_{i}$⁠, ⁠$\mathrm {d} t$⁠ on the two sides}@}: {@{$${\frac {\partial {\mathcal {H} } }{\partial q^{i} } }=-{\frac {\partial {\mathcal {L} } }{\partial q^{i} } }\quad ,\quad {\frac {\partial {\mathcal {H} } }{\partial p_{i} } }={\dot {q} }^{i}\quad ,\quad {\frac {\partial {\mathcal {H} } }{\partial t} }=-{\partial {\mathcal {L} } \over \partial t}\ .$$}@} {@{On-shell, one substitutes parametric functions $q^{i}=q^{i}(t)$}@} which define {@{a trajectory in phase space with velocities ⁠${\dot {q} }^{i}={\tfrac {d}{dt} }q^{i}(t)$⁠}@}, obeying {@{[Lagrange's equations](Euler–Lagrange%20equation.md)}@}: {@{$${\frac {\mathrm {d} }{\mathrm {d} t} }{\frac {\partial {\mathcal {L} } }{\partial {\dot {q} }^{i} } }-{\frac {\partial {\mathcal {L} } }{\partial q^{i} } }=0\ .$$}@} {@{Rearranging and writing in terms of the on-shell $p_{i}=p_{i}(t)$}@} gives: {@{$${\frac {\partial {\mathcal {L} } }{\partial q^{i} } }={\dot {p} }_{i}\ .$$}@} Thus {@{Lagrange's equations are equivalent to Hamilton's equations}@}: {@{$${\frac {\partial {\mathcal {H} } }{\partial q^{i} } }=-{\dot {p} }_{i}\quad ,\quad {\frac {\partial {\mathcal {H} } }{\partial p_{i} } }={\dot {q} }^{i}\quad ,\quad {\frac {\partial {\mathcal {H} } }{\partial t} }=-{\frac {\partial {\mathcal {L} } }{\partial t} }\,.$$}@}

In the case of {@{time-independent ${\mathcal {H} }$ and ⁠${\mathcal {L} }$⁠, i.e. ⁠$\partial {\mathcal {H} }/\partial t=-\partial {\mathcal {L} }/\partial t=0$}@}⁠, {@{Hamilton's equations consist of 2<!-- markdown separator -->_n_ first-order [differential equations](differential%20equation.md)}@}, while {@{Lagrange's equations consist of _n_ second-order equations}@}. {@{Hamilton's equations}@} usually do not {@{reduce the difficulty of finding explicit solutions}@}, but {@{important theoretical results can be derived from them}@}, because {@{coordinates and momenta are independent variables with nearly symmetric roles}@}.

{@{Hamilton's equations}@} have {@{another advantage over Lagrange's equations}@}: if {@{a system has a symmetry}@}, so that {@{some coordinate $q_{i}$ does not occur in the Hamiltonian \(i.e. a _cyclic coordinate_\)}@}, {@{the corresponding momentum coordinate $p_{i}$}@} is {@{conserved along each trajectory}@}, and that coordinate can be {@{reduced to a constant in the other equations of the set}@}. This effectively reduces {@{the problem from _n_ coordinates to \(_n_ − 1\) coordinates}@}: this is the basis of {@{[symplectic reduction](symplectic%20reduction.md#symplectic%20quotients) in geometry}@}. In {@{the Lagrangian framework}@}, {@{the conservation of momentum also follows immediately}@}, however all {@{the generalized velocities ${\dot {q} }_{i}$ still occur in the Lagrangian}@}, and {@{a system of equations in _n_ coordinates still has to be solved}@}.<sup>[\[4\]](#^ref-4)</sup>

{@{The Lagrangian and Hamiltonian approaches}@} provide {@{the groundwork for deeper results in classical mechanics}@}, and suggest {@{analogous formulations in [quantum mechanics](quantum%20mechanics.md)}@}: {@{the [path integral formulation](path%20integral%20formulation.md) and the [Schrödinger equation](Schrödinger%20equation.md)}@}.

## properties of the Hamiltonian

- {@{The value of the Hamiltonian ${\mathcal {H} }$}@} is {@{the total energy of the system}@} {@{if and only if the energy function $E_{\mathcal {L} }$ has the same property}@}. \(See {@{definition of ⁠${\mathcal {H} }$}@}⁠\).<sup>\[_[clarification needed](https://en.wikipedia.org/wiki/Wikipedia:Please%20clarify)_\]</sup>

-{@{ ${\frac {d{\mathcal {H} } }{dt} }={\frac {\partial {\mathcal {H} } }{\partial t} }$}@} when {@{⁠$\mathbf {p} (t)$⁠, ⁠$\mathbf {q} (t)$⁠ form a solution of Hamilton's equations}@}. <p> Indeed, {@{${\frac {d{\mathcal {H} } }{dt} }={\frac {\partial {\mathcal {H} } }{\partial {\boldsymbol {p} } } }\cdot {\dot {\boldsymbol {p} } }+{\frac {\partial {\mathcal {H} } }{\partial {\boldsymbol {q} } } }\cdot {\dot {\boldsymbol {q} } }+{\frac {\partial {\mathcal {H} } }{\partial t} }$}@}, and {@{everything but the final term cancels out}@}.

- {@{${\mathcal {H} }$ does not change}@} under {@{_point transformations_, i.e. smooth changes ${\boldsymbol {q} }\leftrightarrow {\boldsymbol {q'} }$ of space coordinates}@}. \(Follows from {@{the invariance of the energy function $E_{\mathcal {L} }$ under point transformations}@}. {@{The invariance of $E_{\mathcal {L} }$}@} can be {@{established directly}@}\).

- (annotation: {@{partial time derivative}@}) {@{${\frac {\partial {\mathcal {H} } }{\partial t} }=-{\frac {\partial {\mathcal {L} } }{\partial t} }$}@}. \(See {@{_[§ Deriving Hamilton's equations](#Deriving%20Hamilton's%20equations)_}@}\).

- {@{⁠$-{\frac {\partial {\mathcal {H} } }{\partial q^{i} } }={\dot {p} }_{i}={\frac {\partial {\mathcal {L} } }{\partial q^{i} } }$⁠}@}. \(Compare {@{Hamilton's and Euler–Lagrange equations or see _[§ Deriving Hamilton's equations](#Deriving%20Hamilton's%20equations)_}@}\).

- {@{${\frac {\partial {\mathcal {H} } }{\partial q^{i} } }=0$ if and only if ⁠${\frac {\partial {\mathcal {L} } }{\partial q^{i} } }=0$}@}⁠. <p> {@{A coordinate for which the last equation holds}@} is called {@{_cyclic_ \(or _ignorable_\)}@}. {@{Every cyclic coordinate $q^{i}$}@} reduces {@{the number of degrees of freedom by ⁠$1$}@}⁠, causes {@{the corresponding momentum $p_{i}$ to be conserved}@}, and makes {@{Hamilton's equations [easier](Routhian%20mechanics.md) to solve}@}.

## Hamiltonian as the total system energy

In its {@{application to a given system}@}, {@{the Hamiltonian}@} is often {@{taken to be $${\mathcal {H} }=T+V$$}@} where {@{$T$ is the kinetic energy and $V$ is the potential energy}@}. Using {@{this relation}@} can be {@{simpler than first calculating the Lagrangian, and then deriving the Hamiltonian from the Lagrangian}@}. However, {@{the relation is not true for all systems}@}.

The relation holds {@{true for nonrelativistic systems}@} when {@{all of the following conditions are satisfied}@}<sup>[\[5\]](#^ref-5)</sup><sup>[\[6\]](#^ref-6)</sup> {@{$${\frac {\partial V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }=0\;,\quad \forall i$$}@} <br/> {@{$${\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial t} }=0$$}@} <br/> {@{$$T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })=\sum _{i=1}^{n}\sum _{j=1}^{n}{\biggl (}c_{ij}({\boldsymbol {q} }){\dot {q} }_{i}{\dot {q} }_{j}{\biggr )}$$}@} where {@{$t$ is time, $n$ is the number of degrees of freedom of the system}@}, and each $c_{ij}({\boldsymbol {q} })$ is {@{an arbitrary scalar function of ${\boldsymbol {q} }$}@}.

In words, this means that {@{the relation ${\mathcal {H} }=T+V$ holds true}@} if $T$ {@{does not contain time as an explicit variable \(it is [scleronomic](scleronomic.md)\)}@}, $V$ {@{does not contain generalised velocity as an explicit variable}@}, and each term of {@{$T$ is quadratic in generalised velocity}@}.

### proof

{@{Preliminary}@} to this proof, it is important to address {@{an ambiguity in the related mathematical notation}@}. While {@{a change of variables}@} can be used to {@{equate ${\mathcal {L} }({\boldsymbol {p} },{\boldsymbol {q} },t)={\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)$}@}, it is important to note that {@{${\frac {\partial {\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }\neq {\frac {\partial {\mathcal {L} }({\boldsymbol {p} },{\boldsymbol {q} },t)}{\partial {\dot {q} }_{i} } }$}@}. In this case, {@{the right hand side always evaluates to 0}@}. To perform {@{a change of variables inside of a partial derivative}@}, {@{the [multivariable chain rule](chain%20rule.md#multivariable%20case)}@} should be used. Hence, to {@{avoid ambiguity}@}, {@{the function arguments}@} of {@{any term inside of a partial derivative}@} should be stated.

Additionally, {@{this proof}@} uses {@{the notation $f(a,b,c)=f(a,b)$}@} to imply that {@{${\frac {\partial f(a,b,c)}{\partial c} }=0$}@}.

> {@{__Proof__ (annotation: of Hamiltonian as the total system energy)}@}
>
> Starting from {@{definitions of the Hamiltonian, generalized momenta, and Lagrangian}@} for {@{an $n$ degrees of freedom system}@} {@{$${\mathcal {H} }=\sum _{i=1}^{n}{\biggl (}p_{i}{\dot {q} }_{i}{\biggr )}-{\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)$$}@} <br/> {@{$$p_{i}({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)={\frac {\partial {\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }$$}@} <br/> {@{$${\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)=T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)-V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)$$}@}
>
> Substituting {@{the generalized momenta into the Hamiltonian}@} gives {@{$${\mathcal {H} }=\sum _{i=1}^{n}\left({\frac {\partial {\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}\right)-{\mathcal {L} }({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)$$}@}
>
> Substituting {@{the Lagrangian into the result}@} gives {@{$${\begin{aligned}{\mathcal {H} }&=\sum _{i=1}^{n}\left({\frac {\partial \left(T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)-V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)\right)}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}\right)-\left(T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)-V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)\right)\\&=\sum _{i=1}^{n}\left({\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}-{\frac {\partial V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}\right)-T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)+V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)\end{aligned} }$$}@}
>
> Now assume that {@{$${\frac {\partial V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial {\dot {q} }_{i} } }=0\;,\quad \forall i$$}@} and also assume that {@{$${\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial t} }=0$$}@}
>
> {@{Applying these assumptions}@} results in {@{$${\begin{aligned}{\mathcal {H} }&=\sum _{i=1}^{n}\left({\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}-{\frac {\partial V({\boldsymbol {q} },t)}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}\right)-T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })+V({\boldsymbol {q} },t)\\&=\sum _{i=1}^{n}\left({\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}\right)-T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })+V({\boldsymbol {q} },t)\end{aligned} }$$}@}
>
> Next assume that T is {@{of the form $$T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })=\sum _{i=1}^{n}\sum _{j=1}^{n}{\biggl (}c_{ij}({\boldsymbol {q} }){\dot {q} }_{i}{\dot {q} }_{j}{\biggr )}$$}@} where each $c_{ij}({\boldsymbol {q} })$ is {@{an arbitrary scalar function of ${\boldsymbol {q} }$}@}.
>
> {@{Differentiating this with respect to ${\dot {q} }_{l}$, $l\in [1,n]$}@}, gives {@{$${\begin{aligned}{\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })}{\partial {\dot {q} }_{l} } }&=\sum _{i=1}^{n}\sum _{j=1}^{n}{\biggl (}{\frac {\partial \left[c_{ij}({\boldsymbol {q} }){\dot {q} }_{i}{\dot {q} }_{j}\right]}{\partial {\dot {q} }_{l} } }{\biggr )}\\&=\sum _{i=1}^{n}\sum _{j=1}^{n}{\biggl (}c_{ij}({\boldsymbol {q} }){\frac {\partial \left[{\dot {q} }_{i}{\dot {q} }_{j}\right]}{\partial {\dot {q} }_{l} } }{\biggr )}\end{aligned} }$$}@}
>
> Splitting {@{the summation, evaluating the partial derivative, and rejoining the summation}@} gives {@{$${\begin{aligned}{\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })}{\partial {\dot {q} }_{l} } }&=\sum _{i\neq l}^{n}\sum _{j\neq l}^{n}{\biggl (}c_{ij}({\boldsymbol {q} }){\frac {\partial \left[{\dot {q} }_{i}{\dot {q} }_{j}\right]}{\partial {\dot {q} }_{l} } }{\biggr )}+\sum _{i\neq l}^{n}{\biggl (}c_{il}({\boldsymbol {q} }){\frac {\partial \left[{\dot {q} }_{i}{\dot {q} }_{l}\right]}{\partial {\dot {q} }_{l} } }{\biggr )}+\sum _{j\neq l}^{n}{\biggl (}c_{lj}({\boldsymbol {q} }){\frac {\partial \left[{\dot {q} }_{l}{\dot {q} }_{j}\right]}{\partial {\dot {q} }_{l} } }{\biggr )}+c_{ll}({\boldsymbol {q} }){\frac {\partial \left[{\dot {q} }_{l}^{2}\right]}{\partial {\dot {q} }_{l} } }\\&=\sum _{i\neq l}^{n}\sum _{j\neq l}^{n}{\biggl (}0{\biggr )}+\sum _{i\neq l}^{n}{\biggl (}c_{il}({\boldsymbol {q} }){\dot {q} }_{i}{\biggr )}+\sum _{j\neq l}^{n}{\biggl (}c_{lj}({\boldsymbol {q} }){\dot {q} }_{j}{\biggr )}+2c_{ll}({\boldsymbol {q} }){\dot {q} }_{l}\\&=\sum _{i=1}^{n}{\biggl (}c_{il}({\boldsymbol {q} }){\dot {q} }_{i}{\biggr )}+\sum _{j=1}^{n}{\biggl (}c_{lj}({\boldsymbol {q} }){\dot {q} }_{j}{\biggr )}\end{aligned} }$$}@}
>
> {@{Summing \(this multiplied by ${\dot {q} }_{l}$\) over $l$}@} results in {@{$${\begin{aligned}\sum _{l=1}^{n}\left({\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })}{\partial {\dot {q} }_{l} } }{\dot {q} }_{l}\right)&=\sum _{l=1}^{n}\left(\left(\sum _{i=1}^{n}{\biggl (}c_{il}({\boldsymbol {q} }){\dot {q} }_{i}{\biggr )}+\sum _{j=1}^{n}{\biggl (}c_{lj}({\boldsymbol {q} }){\dot {q} }_{j}{\biggr )}\right){\dot {q} }_{l}\right)\\&=\sum _{l=1}^{n}\sum _{i=1}^{n}{\biggl (}c_{il}({\boldsymbol {q} }){\dot {q} }_{i}{\dot {q} }_{l}{\biggr )}+\sum _{l=1}^{n}\sum _{j=1}^{n}{\biggl (}c_{lj}({\boldsymbol {q} }){\dot {q} }_{j}{\dot {q} }_{l}{\biggr )}\\&=\sum _{i=1}^{n}\sum _{l=1}^{n}{\biggl (}c_{il}({\boldsymbol {q} }){\dot {q} }_{i}{\dot {q} }_{l}{\biggr )}+\sum _{l=1}^{n}\sum _{j=1}^{n}{\biggl (}c_{lj}({\boldsymbol {q} }){\dot {q} }_{l}{\dot {q} }_{j}{\biggr )}\\&=T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })+T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })\\&=2T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })\end{aligned} }$$}@}
>
> {@{This simplification}@} is {@{a result of [Euler's homogeneous function theorem](homogeneous%20function.md#Euler's%20theorem)}@}.
>
> Hence, {@{the Hamiltonian}@} becomes {@{$${\begin{aligned}{\mathcal {H} }&=\sum _{i=1}^{n}\left({\frac {\partial T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })}{\partial {\dot {q} }_{i} } }{\dot {q} }_{i}\right)-T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })+V({\boldsymbol {q} },t)\\&=2T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })-T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })+V({\boldsymbol {q} },t)\\&=T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })+V({\boldsymbol {q} },t)\end{aligned} }$$}@}

### application to systems of point masses

For {@{a system of point masses}@}, {@{the requirement for $T$ to be quadratic in generalised velocity}@} is {@{always satisfied for the case where $T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)=T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })$}@}, which is {@{a requirement for ${\mathcal {H} }=T+V$}@} anyway.

> {@{__Proof__ (annotation: of time-independent $T$ being quadratic in generalised velocity for a system of point masses)}@}
>
> Consider {@{the kinetic energy for a system of N point masses}@}. If it is assumed that {@{$T({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)=T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })$}@}, then it can be shown that {@{${\dot {\mathbf {r} } }_{k}({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)={\dot {\mathbf {r} } }_{k}({\boldsymbol {q} },{\boldsymbol {\dot {q} } })$}@} \(See {@{_[Scleronomous § Application](scleronomous.md#application)_}@}\). Therefore, {@{the kinetic energy}@} is {@{$$T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })={\frac {1}{2} }\sum _{k=1}^{N}{\biggl (}m_{k}{\dot {\mathbf {r} } }_{k}({\boldsymbol {q} },{\boldsymbol {\dot {q} } })\cdot {\dot {\mathbf {r} } }_{k}({\boldsymbol {q} },{\boldsymbol {\dot {q} } }){\biggr )}$$}@}
>
> {@{The chain rule for many variables}@} can be used to {@{expand the velocity}@} {@{$${\begin{aligned}{\dot {\mathbf {r} } }_{k}({\boldsymbol {q} },{\boldsymbol {\dot {q} } })&={\frac {d\mathbf {r} _{k}({\boldsymbol {q} })}{dt} }\\&=\sum _{i=1}^{n}\left({\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{i} } }{\dot {q} }_{i}\right)\end{aligned} }$$}@}
>
> Resulting in {@{$${\begin{aligned}T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })&={\frac {1}{2} }\sum _{k=1}^{N}\left(m_{k}\left(\sum _{i=1}^{n}\left({\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{i} } }{\dot {q} }_{i}\right)\cdot \sum _{j=1}^{n}\left({\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{j} } }{\dot {q} }_{j}\right)\right)\right)\\&=\sum _{k=1}^{N}\sum _{i=1}^{n}\sum _{j=1}^{n}\left({\frac {1}{2} }m_{k}{\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{i} } }\cdot {\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{j} } }{\dot {q} }_{i}{\dot {q} }_{j}\right)\\&=\sum _{i=1}^{n}\sum _{j=1}^{n}\left(\sum _{k=1}^{N}\left({\frac {1}{2} }m_{k}{\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{i} } }\cdot {\frac {\partial \mathbf {r} _{k}({\boldsymbol {q} })}{\partial q_{j} } }\right){\dot {q} }_{i}{\dot {q} }_{j}\right)\\&=\sum _{i=1}^{n}\sum _{j=1}^{n}{\biggl (}c_{ij}({\boldsymbol {q} }){\dot {q} }_{i}{\dot {q} }_{j}{\biggr )}\end{aligned} }$$}@}
>
> This is of {@{the required form}@}.

### conservation of energy

If {@{the conditions for ${\mathcal {H} }=T+V$ are satisfied}@}, then {@{conservation of the Hamiltonian implies conservation of energy}@}. This requires {@{the additional condition that $V$ does not contain time as an explicit variable}@}. {@{$${\frac {\partial V({\boldsymbol {q} },{\boldsymbol {\dot {q} } },t)}{\partial t} }=0$$}@}

In summary, {@{the requirements for ${\mathcal {H} }=T+V={\text{constant of time} }$ to be satisfied}@} for {@{a nonrelativistic system}@} are<sup>[\[5\]](#^ref-5)</sup><sup>[\[6\]](#^ref-6)</sup> (annotation: 3 items: {@{$V(\boldsymbol q)$, $T(\boldsymbol q, \boldsymbol{\dot q})$, $T$ is a homogeneous quadratic function in $\boldsymbol{\dot q}$}@})

1. $$V=V({\boldsymbol {q} })$$
2. $$T=T({\boldsymbol {q} },{\boldsymbol {\dot {q} } })$$
3. $T$ is a homogeneous quadratic function in ${\boldsymbol {\dot {q} } }$

Regarding extensions to {@{the Euler-Lagrange formulation which use dissipation functions}@} \(See {@{_[Lagrangian mechanics § Extensions to include non-conservative forces](Lagrangian%20mechanics.md#extensions%20to%20include%20non-conservative%20forces)_}@}\), e.g. {@{the [Rayleigh dissipation function](Rayleigh%20dissipation%20function.md)}@}, energy is {@{not conserved when a dissipation function has effect}@}. It is possible to explain {@{the link between this and the former requirements}@} by relating {@{the extended and conventional Euler-Lagrange equations}@}: grouping {@{the extended terms into the potential function}@} produces {@{a velocity dependent potential}@}. Hence, {@{the requirements are not satisfied}@} when {@{a dissipation function has effect}@}.

## Hamiltonian of a charged particle in an electromagnetic field

{@{A sufficient illustration of Hamiltonian mechanics}@} is given by {@{the Hamiltonian of a charged particle in an [electromagnetic field](electromagnetic%20field.md)}@}. In {@{[Cartesian coordinates](Cartesian%20coordinates.md) the [Lagrangian](Lagrangian%20mechanics.md#electromagnetism)}@} of {@{a non-relativistic classical particle in an electromagnetic field}@} is \(in [SI Units](SI%20units.md)\): {@{$${\mathcal {L} }=\sum _{i}{\tfrac {1}{2} }m{\dot {x} }_{i}^{2}+\sum _{i}q{\dot {x} }_{i}A_{i}-q\varphi ,$$}@} where _q_ is {@{the [electric charge](electric%20charge.md) of the particle}@}, _φ_ is {@{the [electric scalar potential](electric%20potential.md)}@}, and the _A<sub>i</sub>_ are {@{the components of the [magnetic vector potential](magnetic%20vector%20potential.md)}@} that may {@{all explicitly depend on $x_{i}$ and ⁠$t$}@}⁠. (annotation: Note the Lagrangian here has {@{an additional term $q \mathbf x \cdot \mathbf A$}@} compared to {@{the usual form $L = T - V$}@}.)

{@{This Lagrangian, combined with [Euler–Lagrange equation](Euler–Lagrange%20equation.md)}@}, produces {@{the [Lorentz force](Lorentz%20force.md) law}@} {@{$$m{\ddot {\mathbf {x} } }=q\mathbf {E} +q{\dot {\mathbf {x} } }\times \mathbf {B} \,,$$}@} and is called {@{[minimal coupling](minimal%20coupling.md)}@}. (annotation: Applying {@{the Euler–Lagrange equation $\frac{d}{dt}\frac{\partial L}{\partial \mathbf{\dot{r} } } - \frac{\partial L}{\partial \mathbf{r} } = 0$}@} (remembering to apply {@{the chain rule for the total time derivative}@} {@{$\frac{d}{dt} = \frac{\partial}{\partial t} + (\mathbf{\dot{r} }\cdot\nabla)$ to the vector potential term $\mathbf{A}(t, \mathbf{r})$}@} rather than treating {@{position as independent of time}@}) to {@{$L = \frac{1}{2}m\mathbf{\dot{r} }^2 + q\mathbf{\dot{r} }\cdot\mathbf{A} - q\phi$}@}, {@{the momentum derivative}@} {@{$\frac{d}{dt}(m\mathbf{\dot{r} } + q\mathbf{A}) = m\mathbf{\ddot{r} } + q\frac{\partial \mathbf{A} }{\partial t} + q(\mathbf{\dot{r} }\cdot\nabla)\mathbf{A}$}@} equates to {@{the spatial gradient}@} {@{$\frac{\partial L}{\partial \mathbf{r} } = q\nabla(\mathbf{\dot{r} }\cdot\mathbf{A}) - q\nabla\phi$}@} (where {@{spatial derivatives}@} act {@{strictly on $\mathbf{A}$ and $\phi$}@}, with $\mathbf{\dot{r} }$ treated as {@{an independent velocity vector field coordinate}@}); utilizing {@{the vector identity $\nabla(\mathbf{\dot{r} }\cdot\mathbf{A}) - (\mathbf{\dot{r} }\cdot\nabla)\mathbf{A} = \mathbf{\dot{r} }\times(\nabla\times\mathbf{A})$}@} then yields {@{the Lorentz force law $m\mathbf{\ddot{r} } = q\mathbf{E} + q\mathbf{\dot{r} }\times\mathbf{B}$}@}.)

(annotation: the Lagrangian: {@{${\mathcal {L} }=\sum _{i}{\tfrac {1}{2} }m{\dot {x} }_{i}^{2}+\sum _{i}q{\dot {x} }_{i}A_{i}-q\varphi$}@}) {@{The [canonical momenta](canonical%20momenta.md)}@} are given by: {@{$$p_{i}={\frac {\partial {\mathcal {L} } }{\partial {\dot {x} }_{i} } }=m{\dot {x} }_{i}+qA_{i}.$$}@} {@{The Hamiltonian, as the [Legendre transformation](Legendre%20transformation.md) of the Lagrangian}@}, is therefore: {@{$${\mathcal {H} }=\sum _{i}{\dot {x} }_{i}p_{i}-{\mathcal {L} }=\sum _{i}{\frac {\left(p_{i}-qA_{i}\right)^{2} }{2m} }+q\varphi .$$}@} (annotation: First express {@{the velocity in terms of the canonical momentum}@}: {@{$\dot{x}_i = \frac{p_i - q A_i}{m}$}@}. Substituting {@{$\dot{x}_i$ and $L = \frac{1}{2} m \sum_i \dot{x}_i^2 + q \sum_i \dot{x}_i A_i - q\phi$ into the Legendre transformation $H = \sum_i \dot{x}_i p_i - L$}@} gives: {@{$H = \sum_i \left(\frac{p_i - q A_i}{m}\right) p_i - \left[ \frac{1}{2m} \sum_i (p_i - q A_i)^2 + \frac{q}{m} \sum_i (p_i - q A_i) A_i - q\phi \right]$}@} Grouping {@{the non-potential terms by factoring out $\frac{p_i - q A_i}{m}$}@} yields: {@{$H = \sum_i \frac{p_i - q A_i}{m} \left( p_i - q A_i - \frac{p_i - q A_i}{2} \right) + q\phi = \sum_i \frac{(p_i - q A_i)^2}{2m} + q\phi$}@}) This equation is used frequently in {@{[quantum mechanics](quantum%20mechanics.md)}@}. (annotation: Compare to {@{the usual Hamiltonian $H = T + V = \sum_i \frac {p_i^2} {2m} + V$}@}, we can see {@{the canonical momentum $p_i$ is subtracted by the term $q A_i$}@}.)

(annotation: the Lagrangian: {@{${\mathcal {L} }=\sum _{i}{\tfrac {1}{2} }m{\dot {x} }_{i}^{2}+\sum _{i}q{\dot {x} }_{i}A_{i}-q\varphi$}@}) Under {@{[gauge transformation](gauge%20transformation.md)}@}: {@{$$\mathbf {A} \rightarrow \mathbf {A} +\nabla f\,,\quad \varphi \rightarrow \varphi -{\dot {f} }\,,$$}@} where {@{_f_\(__r__, _t_\) is any scalar function of space and time}@}. The aforementioned {@{Lagrangian, the canonical momenta, and the Hamiltonian}@} transform like: {@{$$L\rightarrow L'=L+q{\frac {df}{dt} }\,,\quad \mathbf {p} \rightarrow \mathbf {p'} =\mathbf {p} +q\nabla f\,,\quad H\rightarrow H'=H-q{\frac {\partial f}{\partial t} }\,,$$}@} (annotation: Aware that {@{$\frac {df} {dt}$ is a total derivative, not a partial derivative}@}.) which still produces {@{the same Hamilton's equation}@}: {@{$${\begin{aligned}\left.{\frac {\partial H'}{\partial {x_{i} } } }\right|_{p'_{i} }&=\left.{\frac {\partial }{\partial {x_{i} } } }\right|_{p'_{i} }({\dot {x} }_{i}p'_{i}-L')=-\left.{\frac {\partial L'}{\partial {x_{i} } } }\right|_{p'_{i} }\\&=-\left.{\frac {\partial L}{\partial {x_{i} } } }\right|_{p'_{i} }-q\left.{\frac {\partial }{\partial {x_{i} } } }\right|_{p'_{i} }{\frac {df}{dt} }\\&=-{\frac {d}{dt} }\left(\left.{\frac {\partial L}{\partial { {\dot {x} }_{i} } } }\right|_{p'_{i} }+q\left.{\frac {\partial f}{\partial {x_{i} } } }\right|_{p'_{i} }\right)\\&=-{\dot {p} }'_{i}\end{aligned} }$$}@} (annotation: Note in this case {@{$\left.\frac {\partial} {\partial x_i}\right|_{p'_{i} } \frac {df} {dt} = \frac d {dt} \left( \left.\frac {\partial f} {\partial x_i}\right|_{p'_{i} } \right)$}@}, though {@{partial derivatives and total derivatives do not commute}@} in general.) In {@{quantum mechanics}@}, {@{the [wave function](wave%20function.md)}@} will also undergo {@{a [local](topological%20group.md) [U\(1\)](U(1).md) group transformation<sup>[\[7\]](#^ref-7)</sup> during the Gauge Transformation}@}, which implies that all {@{physical results must be invariant under local U\(1\) transformations}@}.

## from symplectic geometry to Hamilton's equations

### geometry of Hamiltonian systems

{@{The Hamiltonian}@} can induce {@{a [symplectic structure](symplectic%20structure.md)}@} on {@{a [smooth even-dimensional manifold](smooth%20manifold.md#definition) _M_<sup>2<!-- markdown separator -->_n_</sup>}@} in {@{several equivalent ways, the best known being the following}@}:<sup>[\[8\]](#^ref-8)</sup>

(annotation: Consider the Hamiltonian) As {@{a [closed](closed%20differential%20form.md) [nondegenerate](nondegenerate%20form.md#nondegenerate%20forms) [symplectic](symplectic%20manifold.md) [2-form](2-form.md) _ω_}@}. According to {@{[Darboux's theorem](Darboux's%20theorem.md)}@}, in {@{a small neighbourhood around any point on _M_}@} there exist {@{suitable local coordinates $p_{1},\cdots ,p_{n},\ q_{1},\cdots ,q_{n}$ \(_[canonical](canonical%20coordinates.md)_ or _symplectic_ coordinates\)}@} in which {@{the symplectic form}@} becomes: {@{$$\omega =\sum _{i=1}^{n}dp_{i}\wedge dq_{i}\,.$$}@} {@{The form $\omega$}@} induces {@{a [natural isomorphism](natural%20isomorphism.md#natural%20isomorphism) of the [tangent space](tangent%20space.md) with the [cotangent space](cotangent%20space.md)}@}: {@{⁠$T_{x}M\cong T_{x}^{*}M$}@}⁠. This is done by mapping {@{a vector $\xi \in T_{x}M$ to the 1-form ⁠$\omega _{\xi }\in T_{x}^{*}M$}@}⁠, where {@{$\omega _{\xi }(\eta )=\omega (\eta ,\xi )$ for all ⁠$\eta \in T_{x}M$⁠}@}. (annotation: In {@{matrix terms}@}, this theorem guarantees {@{a local change of basis that transforms the symplectic form $\omega$}@} from {@{an arbitrary position-dependent matrix $\Omega(x)$ representing $\omega$}@} into {@{the constant standard matrix $\Omega = \begin{pmatrix} 0 & -I_n \\ I_n & 0 \end{pmatrix}$ (in the ordered $(dq, dp)$ cotangent basis)}@}. Its {@{inverse $J = \Omega^{-1} = \begin{pmatrix} 0 & I_n \\ -I_n & 0 \end{pmatrix}$}@} then yields {@{the standard Poisson matrix for the induced isomorphism $T^*_x M \cong T_x M$}@}.) Due to {@{the [bilinearity](bilinear%20form.md) and non-degeneracy of ⁠$\omega$}@}⁠, and the fact that {@{⁠$\dim T_{x}M=\dim T_{x}^{*}M$}@}⁠, {@{the mapping $\xi \to \omega _{\xi }$}@} is {@{indeed a [linear isomorphism](linear%20isomorphism.md)}@}. {@{This isomorphism is _natural_}@} in that it {@{does not change with change of coordinates on $M$}@}. Repeating {@{over all ⁠$x\in M$}@}⁠, we end up with {@{an isomorphism $J^{-1}:{\text{Vect} }(M)\to \Omega ^{1}(M)$}@} between {@{the infinite-dimensional space of smooth vector fields and that of smooth 1-forms}@}. For every {@{$f,g\in C^{\infty }(M,\mathbb {R} )$ and ⁠$\xi ,\eta \in {\text{Vect} }(M)$}@}⁠, {@{$$J^{-1}(f\xi +g\eta )=fJ^{-1}(\xi )+gJ^{-1}(\eta ).$$}@} \(In {@{algebraic terms}@}, one would say that the {@{$C^{\infty }(M,\mathbb {R} )$-modules ${\text{Vect} }(M)$ and $\Omega ^{1}(M)$ are isomorphic}@}\). If ⁠{@{$H\in C^{\infty }(M\times \mathbb {R} _{t},\mathbb {R} )$⁠}@}, then, for every {@{fixed ⁠$t\in \mathbb {R} _{t}$}@}⁠, {@{⁠$dH\in \Omega ^{1}(M)$⁠, and ⁠$J(dH)\in {\text{Vect} }(M)$}@}⁠. {@{$J(dH)$}@} is known as {@{a [Hamiltonian vector field](Hamiltonian%20vector%20field.md)}@}. {@{The respective differential equation on $M$<!-- markdown separator --> $${\dot {x} }=J(dH)(x)$$}@} is called {@{_Hamilton's equation_}@}. Here {@{$x=x(t)$}@} and {@{$J(dH)(x)\in T_{x}M$}@} is {@{the \(time-dependent\) value of the vector field $J(dH)$ at ⁠$x\in M$⁠}@}. (annotation: In {@{canonical coordinates $x = (q, p)$}@}, {@{the differential 1-form}@} {@{$dH = \begin{pmatrix} \frac{\partial H}{\partial q} \\ \frac{\partial H}{\partial p} \end{pmatrix}$}@} acts as {@{the gradient of $H$}@}. {@{The canonical Poisson matrix}@} {@{$J = \begin{pmatrix} 0 & I_n \\ -I_n & 0 \end{pmatrix}$}@} maps {@{this 1-form into a tangent vector field}@} by swapping {@{the position and momentum components with a sign flip}@}, turning {@{$\dot{x} = J(dH)(x)$ into the classic Hamilton's equations}@}.)

(annotation: To summarize the previous paragraph {@{abstractly without assuming any physical interpretations}@}: For {@{a fixed argument $t$ (time)}@}, {@{a symplectic form $\omega$ on a manifold $M$}@} translates {@{1-forms to vector fields ($T^*M \cong TM$)}@}. Feeding {@{the gradient $dH$ into this map}@} transforms {@{a smooth scalar function $H_t$ (the Hamiltonian at time $t$) into a (Hamiltonian) vector field $X_{H_t} = J(d{H_t})$}@}, directly driving {@{trajectories across the (time-)indexed manifolds (phase spaces) via $\dot{x} = X_{H_t}(x)$}@}. The next paragraph then constructs {@{the required symplectic manifold, i.e. a manifold with a symplectic form}@}, and gives {@{the physical interpretation to the above abstract construction}@} (parenthesized above).)

{@{A Hamiltonian system}@} may be understood as {@{a [fiber bundle](fiber%20bundle.md) _E_ over [time](time.md) _R_}@}, with {@{the [fiber](level%20set.md) _E<sub>t</sub>_}@} being {@{the position space at time _t_ ∈ _R_}@}. (annotation: {@{$E_t$ is a _fiber_}@} because it is {@{the exact preimage $\pi^{-1}(t)$}@} under {@{time projection $\pi: E \to \mathbb{R}$}@}, {@{a position-space slice sitting directly "above" instant $t$}@} containing {@{all possible configuration coordinates $q$ at that moment}@}. {@{The total space $E$ is a _fiber bundle_}@} because it {@{smoothly glues these spatial fibers along the 1D time axis $\mathbb{R}$}@} like {@{pages bound in a book}@}, letting {@{physical trajectories}@} be represented as {@{smooth curves threading through one spatial slice at a time}@}.) {@{The Lagrangian}@} is thus {@{a function on the [jet bundle](jet%20bundle.md) _J_ over _E_}@}; taking {@{the fiberwise [Legendre transform](Legendre%20transform.md) of the Lagrangian}@} produces {@{a function on the dual bundle over time}@} whose fiber {@{at _t_ is the [cotangent space](cotangent%20space.md) _T_<sup>∗</sup>_E<sub>t</sub>_}@}, which comes {@{equipped with a natural [symplectic form](symplectic%20manifold.md)}@}, and this {@{latter function is the Hamiltonian}@}. {@{The correspondence between Lagrangian and Hamiltonian mechanics}@} is achieved with {@{the [tautological one-form](tautological%20one-form.md)}@}. (annotation: {@{The _first jet bundle_ $J^1 E$}@} serves as {@{the time-dependent extension of the _tangent bundle_ $T E$}@}: at {@{every configuration point $(t, q)$}@}, its fiber holds {@{equivalence classes of path derivatives}@} representing {@{instantaneous velocity vectors $\dot{q} \in T_q E_t$}@}, making $J^1 E$ {@{the natural kinematic domain}@} for {@{the Lagrangian function $L(t, q, \dot{q}) = T - V$}@}. {@{The fiberwise Legendre transform}@} (formally {@{the fiber derivative $FL: J^1 E \to T^* E_t$}@}) maps {@{these velocity vectors to linear functional covectors in the _cotangent space_ $T^*_q E_t$}@}, defining {@{the conjugate momentum $p = \frac{\partial L}{\partial \dot{q} }$}@}. This maps {@{the dynamics from velocity space}@} into {@{the _cotangent bundle_ $T^* E_t$ (the classical phase space)}@}, where {@{each fiber}@} intrinsically carries {@{the canonical tautological 1-form $\theta = p_i dq^i$}@} and {@{the non-degenerate symplectic 2-form $\omega = -d\theta = dq^i \wedge dp_i$}@}.)

(annotation: To summarize the previous paragraph paragraph which {@{additionally gives physical meaning to the paragraph that comes before it}@}: {@{Configuration bundle $E \to \mathbb{R}$}@} extends to {@{1-jet velocity space $J^1 E$ carrying the Lagrangian $L$}@}. {@{The fiberwise Legendre transform $FL: J^1 E \to T^ E_t$}@} dualizes {@{velocity vectors $\dot{q} \in T_q E_t$}@} into {@{momentum covectors $p = \frac{\partial L}{\partial \dot{q} } \in T^*_q E_t$}@}. This constructs {@{the cotangent phase space bundle $T^* E_t$}@}, which intrinsically inherits {@{tautological 1-form $\theta = p_i dq^i$ and canonical symplectic form $\omega = -d\theta = dq^i \wedge dp_i$}@}. This constructs {@{the symplectic manifold required in the paragraph that comes before it}@} directly from {@{Lagrangian mechanics}@}, giving {@{the physical interpretation}@}.)

{@{Any [smooth](smooth%20function.md) real-valued function H}@} on {@{a [symplectic manifold](symplectic%20manifold.md)}@} can be used to define {@{a [Hamiltonian system](Hamiltonian%20vector%20field.md)}@}. {@{The function H}@} is known as {@{"the Hamiltonian" or "the energy function"}@}. {@{The symplectic manifold}@} is then called {@{the [phase space](phase%20space.md)}@}. {@{The Hamiltonian}@} induces {@{a special [vector field](symplectic%20vector%20field.md) on the symplectic manifold}@}, known as {@{the [Hamiltonian vector field](Hamiltonian%20vector%20field.md)}@}.

{@{The Hamiltonian vector field}@} induces {@{a [Hamiltonian flow](Hamiltonian%20flow.md) on the manifold}@}. (annotation: Assume the Hamiltonian is {@{autonomous (time-independent), where $\frac{\partial H}{\partial t} = 0$}@}, then...) This is {@{a one-parameter family}@} of {@{transformations of the manifold}@} \({@{the parameter of the curves}@} is commonly called {@{"the time"}@}\); in other words, {@{an [isotopy](homotopy.md#isotopy) of [symplectomorphisms](symplectomorphism.md)}@}, starting with {@{the identity}@}. (annotation: Now the above assumption may be dropped henceforth.) By {@{[Liouville's theorem](Liouville's%20theorem%20(Hamiltonian).md)}@}, {@{each symplectomorphism}@} preserves {@{the [volume form](volume%20form.md) on the [phase space](phase%20space.md)}@}. {@{The collection of symplectomorphisms induced by the Hamiltonian flow}@} is commonly called {@{"the Hamiltonian mechanics" of the Hamiltonian system}@}.

{@{The symplectic structure}@} induces {@{a [Poisson bracket](Poisson%20bracket.md) (annotation: see below)}@}. {@{The Poisson bracket}@} gives {@{the space of functions on the manifold}@} {@{the structure of a [Lie algebra](Lie%20algebra.md)}@}.

If _F_ and _G_ are {@{smooth functions on _M_}@} then {@{the smooth function _ω_\(_J_\(_dF_\), _J_\(_dG_\)\)}@} is {@{properly defined}@}; it is called {@{a _Poisson bracket_ of functions _F_ and _G_}@} and is denoted {@{<!-- markdown separator -->{_F_, _G_}<!-- markdown separator -->}@}. {@{The Poisson bracket}@} has the following properties: (annotation: 5 items: {@{bilinearity, antisymmetry, Leibniz/product rule, Jacobi identity, non-degeneracy}@})

1. bilinearity
2. antisymmetry
3. [Leibniz rule](product%20rule.md): ::@:: $\{F_{1}\cdot F_{2},G\}=F_{1}\{F_{2},G\}+F_{2}\{F_{1},G\}$
4. [Jacobi identity](Jacobi%20identity.md): ::@:: $\{\{H,F\},G\}+\{\{F,G\},H\}+\{\{G,H\},F\}\equiv 0$
5. non-degeneracy: ::@:: if the point _x_ on _M_ is not critical for _F_ then a smooth function _G_ exists such that ⁠$\{F,G\}(x)\neq 0$⁠.

Given {@{a function _f_}@} {@{$${\frac {\mathrm {d} }{\mathrm {d} t} }f={\frac {\partial }{\partial t} }f+\left\{f,{\mathcal {H} }\right\},$$}@} (annotation: This holds {@{for any smooth function $f$}@}. To derive it: {@{$$\begin{aligned} \frac{df}{dt} &\stackrel{\text{(1)} }{=} \frac{\partial f}{\partial t} + \sum_i \left( \frac{\partial f}{\partial q_i} \dot{q}_i + \frac{\partial f}{\partial p_i} \dot{p}_i \right) \\ &\stackrel{\text{(2)} }{=} \frac{\partial f}{\partial t} + \sum_i \left( \frac{\partial f}{\partial q_i} \frac{\partial H}{\partial p_i} - \frac{\partial f}{\partial p_i} \frac{\partial H}{\partial q_i} \right) \\ &\stackrel{\text{(3)} }{=} \frac{\partial f}{\partial t} + \{f, H\} \end{aligned}$$}@}) if there is {@{a [probability distribution](probability%20distribution.md) _ρ_}@}, then \(since {@{the phase space velocity $({\dot {p} }_{i},{\dot {q} }_{i})$ has zero divergence}@} (annotation: derivation: {@{$$\begin{aligned} \nabla \cdot \mathbf{v} &\stackrel{\text{(1)} }{=} \sum_{i=1}^n \left( \frac{\partial \dot{q}_i}{\partial q_i} + \frac{\partial \dot{p}_i}{\partial p_i} \right) \\ &\stackrel{\text{(2)} }{=} \sum_{i=1}^n \left( \frac{\partial}{\partial q_i}\frac{\partial H}{\partial p_i} + \frac{\partial}{\partial p_i}\left(-\frac{\partial H}{\partial q_i}\right) \right) \\ &\stackrel{\text{(3)} }{=} \sum_{i=1}^n \left( \frac{\partial^2 H}{\partial q_i \partial p_i} - \frac{\partial^2 H}{\partial p_i \partial q_i} \right) \stackrel{\text{(4)} }{=} 0 \end{aligned}$$}@}) and {@{probability is conserved (annotation: i.e. continuity equation in phase space $\frac {\partial \rho} {\partial t} = -\nabla \cdot (\rho \mathbf v) = - \nabla \rho \cdot \mathbf v$ since $\rho \nabla \cdot \mathbf v = 0$)}@}\) its {@{convective derivative can be shown to be zero (annotation: $\frac {d\rho} {dt} = \frac {\partial \rho} {\partial t} + \nabla \rho \cdot \mathbf v = 0$)}@} and so {@{$${\frac {\partial }{\partial t} }\rho =-\left\{\rho ,{\mathcal {H} }\right\}$$}@} This is called {@{[Liouville's theorem](Liouville's%20theorem%20(Hamiltonian).md)}@}. Every {@{[smooth function](smooth%20function.md) _G_ over the [symplectic manifold](symplectic%20manifold.md) (annotation: assume the partial derivative of _G_ is zero)}@} generates {@{a one-parameter family of [symplectomorphisms](symplectomorphism.md)}@} and if {@{<!-- markdown separator -->{_G_, _H_} = 0}@}, then {@{_G_ is conserved}@} and the symplectomorphisms are {@{[symmetry transformations](symmetry%20transformation.md)}@}.

{@{A Hamiltonian}@} may have {@{multiple conserved quantities _G_<sub>_i_</sub>}@}. If {@{the symplectic manifold has dimension 2<!-- markdown separator -->_n_}@} and there are {@{_n_ functionally independent conserved quantities _G<sub>i</sub>_}@} which are in {@{involution \(i.e., {_G_<sub>_i_</sub>, _G_<sub>_j_</sub>} = 0\)}@}, then {@{the Hamiltonian is [Liouville integrable](Liouville%20integrability.md#Hamiltonian%20systems%20and%20Liouville%20integrability)}@}. (annotation: In {@{a $2n$-dimensional phase space}@}, each {@{conserved quantity $G_i$}@} restricts {@{system trajectories to a surface of one lower dimension}@}, while {@{involution ($\{G_i, G_j\} = 0$)}@} ensures their {@{generated Hamiltonian flows commute so all constraints apply simultaneously}@}. Having {@{$n$ independent conserved quantities in involution}@} confines {@{the motion to invariant $n$-dimensional tori}@}, making {@{the equations of motion explicitly solvable}@}. For example, {@{a 2D central-force system ($n=2$, 4D phase space)}@} is {@{integrable}@} because {@{total energy $H$ and angular momentum $L_z$}@} satisfy {@{$\{H, L_z\} = 0$}@}, supplying {@{the required two independent quantities}@}.) {@{The [Liouville–Arnold theorem](Liouville–Arnold%20theorem.md)}@} says that, {@{locally, any Liouville integrable Hamiltonian}@} can be {@{transformed via a symplectomorphism}@} into {@{a new Hamiltonian with the conserved quantities _G<sub>i</sub>_ as coordinates}@}; {@{the new coordinates}@} are called {@{_action–angle coordinates_}@}. {@{The transformed Hamiltonian}@} depends {@{only on the _G_<sub>_i_</sub>}@}, and hence {@{the equations of motion have the simple form}@} {@{$${\dot {G} }_{i}=0\quad ,\quad {\dot {\varphi } }_{i}=F_{i}(G)$$ for some function _F_}@}.<sup>[\[9\]](#^ref-9)</sup> (annotation: Apply {@{Hamilton's equations to the new Hamiltonian}@}, which is {@{a function of only the $G_i$ coordinates}@}.) There is {@{an entire field focusing on small deviations from integrable systems}@} governed by {@{the [KAM theorem](KAM%20theorem.md)}@}.

> (annotation: Consider {@{a planet of mass $m$}@} orbiting {@{a star under Newtonian gravity}@} with {@{potential $V(r) = -\frac{k}{r}$ (where $k = G M m$)}@}, governed by {@{$H(r, \theta, p_r, p_\theta) = \frac{p_r^2}{2m} + \frac{p_\theta^2}{2m r^2} - \frac{k}{r} = E < 0$}@}. For {@{bounded periodic motion}@}, each {@{_action variable_}@} is defined by {@{$I_i = \frac{1}{2\pi} \oint p_i \, dq_i$}@}, which integrates {@{momentum $p_i$ over one full cycle of coordinate $q_i$}@} to measure {@{the conserved phase-space area}@}. Since {@{$\theta$ is cyclic}@}, {@{angular momentum $p_\theta = L_z$ is constant}@}, yielding {@{$I_\theta = \frac{1}{2\pi} \int_0^{2\pi} L_z \, d\theta = L_z$}@}. For {@{the radial action $I_r = \frac{1}{2\pi} \oint p_r \, dr$}@}, isolating {@{radial momentum gives $p_r(r) = \frac{\sqrt{2mEr^2 + 2mkr - L_z^2} }{r}$}@}. {@{The physical integration path $C$}@} wraps around {@{the branch cut $[r_{\text{min} }, r_{\text{max} }]$}@}, across which $p_r$ {@{flips sign between outward and inward motion}@}. By compactifying {@{the complex plane into the _Riemann sphere_ $\hat{\mathbb{C} } = \mathbb{C} \cup \{\infty\}$}@}, deforming {@{$C$ outward across the sphere}@} converts {@{the contour integral into $-2\pi i$ times the sum of residues}@} at {@{the remaining isolated poles on $\hat{\mathbb{C} }$ outside the loop ($r = 0$ and $r = \infty$)}@}:
>
> - {@{At $r = 0$}@}: {@{Analytic continuation of the radical}@} to $r < r_{\text{min} }$ yields {@{$p_r(r) = \frac{-i L_z}{r}\sqrt{1 - \frac{2mkr}{L_z^2} - \frac{2mEr^2}{L_z^2} }$}@}. {@{Taylor expanding $\sqrt{1 - x} \approx 1 - \frac{1}{2}x$ near $r = 0$}@} gives {@{$p_r(r) = -\frac{i L_z}{r} + \frac{i mk}{L_z} + O(r)$}@}, identifying {@{a simple pole with residue $\text{Res}(p_r, 0) = -i L_z$}@}.
> - {@{At $r = \infty$}@}: {@{Factoring out $2mE = -2m\vert{}E\vert{}$}@} for large $r$ (so $1 / r$ is small) yields {@{$p_r(r) = i\sqrt{-2mE}\sqrt{1 + \frac{k}{Er} - \frac{L_z^2}{2mEr^2} }$}@}. Expanding {@{$\sqrt{1 + x} \approx 1 + \frac{1}{2}x$ in powers of $1/r$}@} gives {@{$p_r(r) = i\sqrt{-2mE} - \frac{i mk}{\sqrt{-2mE} \cdot r} + O(1/r^2)$}@}, yielding {@{the Laurent coefficient $c_{-1} = -\frac{i mk}{\sqrt{-2mE} }$}@} and corresponding {@{residue at infinity $\text{Res}(p_r, \infty) = -c_{-1} = \frac{i mk}{\sqrt{-2mE} }$}@}.
>
> Summing {@{the residues on the Riemann sphere}@} yields {@{$\oint_C p_r \, dr = -2\pi i \left[ \text{Res}(p_r, 0) + \text{Res}(p_r, \infty) \right] = -2\pi i \left( -i L_z + \frac{i mk}{\sqrt{-2mE} } \right) = 2\pi \left( \frac{mk}{\sqrt{-2mE} } - L_z \right)$}@}, which simplifies to {@{$I_r = \frac{mk}{\sqrt{-2mE} } - L_z = \frac{mk}{\sqrt{-2mE} } - I_\theta$}@}. {@{Inverting this relation for total energy $E$}@} gives {@{$\sqrt{-2mE} = \frac{mk}{I_r + I_\theta}$}@}, which squares to {@{the transformed Hamiltonian $K(I_r, I_\theta) = -\frac{m k^2}{2 (I_r + I_\theta)^2}$}@}. {@{Differentiating $K$ with respect to each action}@} yields {@{the fundamental frequencies $\omega_r = \frac{\partial K}{\partial I_r} = \frac{m k^2}{(I_r + I_\theta)^3}$}@} and {@{$\omega_\theta = \frac{\partial K}{\partial I_\theta} = \frac{m k^2}{(I_r + I_\theta)^3}$}@}. Intuitively, {@{$K(I_r, I_\theta)$}@} replaces {@{complex spatial trajectories with two static actions}@}, revealing that {@{the radial and angular frequencies are identical ($\omega_r = \omega_\theta$)}@}, proving why {@{Keplerian orbits}@} form {@{closed, non-precessing ellipses}@} while reducing {@{planetary motion to uniform, linear winding around an invariant 2-torus}@} ({@{$T^2 = S^1 \times S^1$}@}).)

{@{The integrability of Hamiltonian vector fields}@} is {@{an open question}@}. In general, {@{Hamiltonian systems are [chaotic](chaos%20theory.md)}@}; {@{concepts of measure, completeness, integrability and stability}@} are {@{poorly defined}@}.

### Riemannian manifolds

{@{An important special case}@} consists of those {@{Hamiltonians that are [quadratic forms](quadratic%20form.md)}@}, that is, Hamiltonians that can be {@{written as $${\mathcal {H} }(q,p)={\tfrac {1}{2} }\langle p,p\rangle _{q}$$}@} where {@{⟨ , ⟩<sub>_q_</sub> is a smoothly varying [inner product](inner%20product.md)}@} on {@{the [fibers](fibre%20bundle.md) _T_<sup>∗</sup> <sub>_q_</sub>_Q_, the [cotangent space](cotangent%20space.md) to the point _q_ in the [configuration space](configuration%20space%20(physics).md)}@}, sometimes called {@{a cometric}@}. {@{This Hamiltonian}@} consists entirely of {@{the kinetic term}@}.

If one considers {@{a [Riemannian manifold](Riemannian%20manifold.md) or a [pseudo-Riemannian manifold](pseudo-Riemannian%20manifold.md)}@}, {@{the [Riemannian metric](metric%20tensor.md)}@} induces {@{a linear isomorphism between the tangent and cotangent bundles}@}. \(See {@{_[Musical isomorphism](musical%20isomorphism.md)_}@}\). Using {@{this isomorphism}@}, one can define {@{a cometric}@}. \(In {@{coordinates}@}, {@{the matrix defining the cometric}@} is {@{the inverse of the matrix defining the metric}@}.\) {@{The solutions to the [Hamilton–Jacobi equations](Hamilton–Jacobi%20equation.md)}@} for {@{this Hamiltonian}@} are then {@{the same as the [geodesics](geodesic.md) on the manifold}@}. In particular, {@{the [Hamiltonian flow](Hamiltonian%20flow.md)}@} in this case is {@{the same thing as the [geodesic flow](geodesic%20flow.md#flow)}@}. {@{The existence of such solutions}@}, and {@{the completeness of the set of solutions}@}, are discussed in detail in {@{the article on [geodesics](geodesic.md)}@}. See also {@{_[Geodesics as Hamiltonian flows](geodesics%20as%20Hamiltonian%20flows.md)_}@}.

### sub-Riemannian manifolds

When {@{the cometric is degenerate}@}, then it is {@{not invertible}@}. In this case, one does not {@{have a Riemannian manifold, as one does not have a metric}@}. However, {@{the Hamiltonian still exists}@}. In the case where {@{the cometric is degenerate at every point _q_ of the configuration space manifold _Q_}@}, so that {@{the [rank](rank%20(linear%20algebra).md) of the cometric}@} is {@{less than the dimension of the manifold _Q_}@}, one has {@{a [sub-Riemannian manifold](Sub-Riemannian%20manifold.md)}@}.

{@{The Hamiltonian}@} in this case is known as {@{a __sub-Riemannian Hamiltonian__}@}. {@{Every such Hamiltonian}@} {@{uniquely determines the cometric, and vice versa}@}. This implies that {@{every [sub-Riemannian manifold](Sub-Riemannian%20manifold.md)}@} is {@{uniquely determined by its sub-Riemannian Hamiltonian}@}, and that {@{the converse is true}@}: {@{every sub-Riemannian manifold}@} has {@{a unique sub-Riemannian Hamiltonian}@}. {@{The existence of sub-Riemannian geodesics}@} is given by {@{the [Chow–Rashevskii theorem](Chow–Rashevskii%20theorem.md)}@}.

{@{The continuous, real-valued [Heisenberg group](Heisenberg%20group.md)}@} provides {@{a simple example of a sub-Riemannian manifold}@}. For {@{the Heisenberg group}@}, {@{the Hamiltonian}@} is given by {@{$${\mathcal {H} }\left(x,y,z,p_{x},p_{y},p_{z}\right)={\tfrac {1}{2} }\left(p_{x}^{2}+p_{y}^{2}\right).$$}@} {@{_p<sub>z</sub>_}@} is {@{not involved in the Hamiltonian}@}.

### Poisson algebras

{@{Hamiltonian systems}@} can be {@{generalized in various ways}@}. Instead of simply looking at {@{the [algebra](associative%20algebra.md) of [smooth functions](smooth%20function.md)}@} over {@{a [symplectic manifold](symplectic%20manifold.md)}@}, {@{Hamiltonian mechanics}@} can be formulated on {@{general [commutative](commutative.md) [unital](unital%20algebra.md#unital%20algebra) [real](real%20number.md) [Poisson algebras](Poisson%20algebra.md)}@}. {@{A [state](state%20(functional%20analysis).md)}@} is {@{a [continuous](continuity%20(topology).md#continuous%20functions%20between%20topological%20spaces) [linear functional](linear%20functional.md)}@} on {@{the Poisson algebra \(equipped with some suitable [topology](topological%20space.md)\)}@} such that for {@{any element _A_ of the algebra}@}, {@{_A_<sup>2</sup> maps to a nonnegative real number}@}.

{@{A further generalization}@} is given by {@{[Nambu dynamics](Nambu%20dynamics.md)}@}.

### generalization to quantum mechanics through Poisson bracket

{@{Hamilton's equations}@} above work {@{well for [classical mechanics](classical%20mechanics.md)}@}, but not {@{for [quantum mechanics](quantum%20mechanics.md)}@}, since {@{the differential equations discussed}@} assume that one can specify {@{the exact position and momentum of the particle simultaneously at any point in time}@}. However, {@{the equations can be further generalized}@} to then be extended to {@{apply to quantum mechanics as well as to classical mechanics}@}, through {@{the deformation of the [Poisson algebra](Poisson%20algebra.md) over _p_ and _q_}@} to {@{the algebra of [Moyal brackets](Moyal%20bracket.md)}@}.

Specifically, {@{the more general form of the Hamilton's equation}@} reads {@{$${\frac {\mathrm {d} f}{\mathrm {d} t} }=\left\{f,{\mathcal {H} }\right\}+{\frac {\partial f}{\partial t} },$$}@} where {@{_f_ is some function of _p_ and _q_, and H is the Hamiltonian}@}. To find out {@{the rules for evaluating a [Poisson bracket](Poisson%20bracket.md)}@} without {@{resorting to differential equations}@}, see {@{_[Lie algebra](Lie%20algebra.md)_}@}; {@{a Poisson bracket}@} is the name for {@{the Lie bracket in a [Poisson algebra](Poisson%20algebra.md)}@}. {@{These Poisson brackets}@} can then be extended to {@{[Moyal brackets](Moyal%20bracket.md)}@} comporting to {@{an inequivalent Lie algebra, as proven by [Hilbrand J. Groenewold](Hilbrand%20J.%20Groenewold.md)}@}, and thereby describe {@{quantum mechanical diffusion in phase space}@} \(See {@{_[Phase space formulation](phase%20space%20formulation.md)_ and _[Wigner–Weyl transform](Wigner–Weyl%20transform.md)_}@}\). {@{This more algebraic approach}@} not only permits ultimately extending {@{[probability distributions](probability%20distribution.md) in [phase space](phase%20space.md)}@} to {@{[Wigner quasi-probability distributions](Wigner%20quasi-probability%20distribution.md)}@}, but, at {@{the mere Poisson bracket classical setting}@}, also provides more power in helping analyze {@{the relevant [conserved quantities](conserved%20quantity.md) in a system}@}.
