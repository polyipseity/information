# inner measure

In {@{[mathematics](mathematics.md), in particular in [measure theory](measure%20theory.md)}@}, {@{an __inner measure__}@} is {@{a [function](function%20(mathematics).md) on the [power set](power%20set.md) of a given [set](set%20(mathematics).md)}@}, with {@{values in the [extended real numbers](extended%20real%20line.md), satisfying some technical conditions}@}. Intuitively, {@{the inner measure of a set}@} is {@{a lower bound of the size of that set}@}.

## definition

{@{An inner measure}@} is {@{a [set function](set%20function.md) $$\varphi :2^{X}\to [0,\infty ],$$}@} defined on {@{all [subsets](subset.md) of a set $X$}@}, that satisfies {@{the following conditions}@}: (annotation: 4 items: {@{null empty set, superadditive}@}, {@{limits of decreasing towers, infinity must be approached}@})

- Null empty set: ::@:: The [empty set](empty%20set.md) has zero inner measure \(_see also: [measure zero](measure%20zero.md)_\); that is, $$\varphi (\varnothing )=0$$
- [Superadditive](superadditivity.md): ::@:: For any [disjoint](disjoint%20sets.md) sets $A$ and $B$, $$\varphi (A\cup B)\geq \varphi (A)+\varphi (B).$$
- Limits of decreasing towers: ::@:: For any [sequence](sequence.md) $A_{1},A_{2},\ldots$ of sets such that $A_{j}\supseteq A_{j+1}$ for each $j$ and $\varphi (A_{1})<\infty$  $$\varphi \left(\bigcap _{j=1}^{\infty }A_{j}\right)=\lim _{j\to \infty }\varphi (A_{j})$$
- If {@{the measure is not finite}@}, that is, if there {@{exist sets $A$ with $\varphi (A)=\infty$}@}, then {@{this infinity must be approached}@}. More precisely, if {@{$\varphi (A)=\infty$ for a set $A$}@} then for {@{every positive [real number](real%20number.md) $r$}@}, there {@{exists some $B\subseteq A$ such that $$r\leq \varphi (B)<\infty .$$}@}

## the inner measure induced by a measure

Let $\Sigma$ be {@{a [σ-algebra](σ-algebra.md) over a set $X$}@} and $\mu$ be {@{a [measure](measure%20(mathematics).md) on $\Sigma$}@}. Then {@{the inner measure $\mu _{*}$ induced by $\mu$}@} is defined by {@{$$\mu _{*}(T)=\sup\{\mu (S):S\in \Sigma {\text{ and } }S\subseteq T\}.$$}@}

Essentially $\mu _{*}$ gives {@{a lower bound of the size of any set}@} by ensuring {@{it is at least as big as the $\mu$-measure of any of its $\Sigma$-measurable subsets}@}. Even though {@{the set function $\mu _{*}$ is usually not a measure}@}, $\mu _{*}$ shares {@{the following properties with measures}@}: (annotation: 3 items: {@{null empty set, non-negativity, monotonicity}@})

1. (annotation: null empty set) ::@:: $$\mu _{*}(\varnothing )=0,$$
2. (annotation: non-negativity) ::@:: $\mu _{*}$ is non-negative,
3. (annotation: monotonicity) ::@:: If $E\subseteq F$ then $\mu _{*}(E)\leq \mu _{*}(F)$.

## measure completion

- Main article: ::@:: [Complete measure](complete%20measure.md)

{@{Induced inner measures}@} are often used {@{in combination with [outer measures](outer%20measure.md)}@} to {@{extend a measure to a larger σ-algebra}@}. If $\mu$ is {@{a finite measure defined on a [σ-algebra](σ-algebra.md) $\Sigma$ over $X$}@} and $\mu ^{*}$ and $\mu _{*}$ are {@{corresponding induced outer and inner measures}@}, then {@{the sets $T\in 2^{X}$ such that $\mu _{*}(T)=\mu ^{*}(T)$}@} form {@{a σ-algebra ${\hat {\Sigma } }$ with $\Sigma \subseteq {\hat {\Sigma } }$}@}.<sup>[\[1\]](#^ref-1)</sup> {@{The set function ${\hat {\mu } }$}@} defined by {@{$${\hat {\mu } }(T)=\mu ^{*}(T)=\mu _{*}(T)$$ for all $T\in {\hat {\Sigma } }$}@} is {@{a measure on ${\hat {\Sigma } }$ known as the completion of $\mu$}@}.
