# ladder operator

In {@{[linear algebra](linear%20algebra.md) \(and its application to [quantum mechanics](quantum%20mechanics.md)\)}@}, {@{a __raising__ or __lowering operator__ \(collectively known as __ladder operators__\)}@} is {@{an [operator](operator%20(mathematics).md) that increases or decreases the [eigenvalue](eigenvalue.md) of another operator}@}. ## motivation from mathematics

## general formulation

Suppose that {@{two operators _X_ and _N_ have the [commutation relation](commutation%20relation.md)}@} {@{$$[N,X]=cX$$ for some scalar _c_}@}. If {@{${|n\rangle }$ is an eigenstate of _N_}@} with {@{eigenvalue equation $$N|n\rangle =n|n\rangle ,$$}@} then {@{the operator _X_}@} acts on {@{$|n\rangle$ in such a way as to shift the eigenvalue by _c_}@}: {@{$${\begin{aligned}NX|n\rangle &=(XN+[N,X])|n\rangle \\&=XN|n\rangle +[N,X]|n\rangle \\&=Xn|n\rangle +cX|n\rangle \\&=(n+c)X|n\rangle .\end{aligned} }$$}@} In other words, if {@{$|n\rangle$ is an eigenstate of _N_ with eigenvalue _n_}@}, then {@{$X|n\rangle$ is an eigenstate of _N_ with eigenvalue _n_ + _c_ or is zero}@}. {@{The operator _X_}@} is {@{a _raising operator_ for _N_ if _c_ is real and positive}@}, and {@{a _lowering operator_ for _N_ if _c_ is real and negative}@}. <!--SR:!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z!fsrs,2026-11-18T00:00:00.000Z,8,8.2956,1,2,1,0,0,2026-11-10T00:00:00.000Z-->

### factorization method

{@{A suitable factorization}@} is given by<sup>[\[12\]](#^ref-12)</sup> {@{$$C_{l}=p_{r}+{\frac {i\hbar (l+1)}{r} }-i\mu \omega r$$}@} with {@{$$F_{l}=-(2l+3)\mu \omega \hbar$$}@} and {@{$$G_{l}=-(2l+1)\mu \omega \hbar .$$}@} Then {@{$$E_{l+1}^{n^{'} }=E_{l}^{n}+{\frac {F_{l}-G_{l} }{2\mu } }=E_{l}^{n}-\omega \hbar ,$$}@} and {@{continuing this}@}, {@{$${\begin{aligned}E_{l+2}^{n^{'} }&=E_{l}^{n}-2\omega \hbar \\E_{l+3}^{n^{'} }&=E_{l}^{n}-3\omega \hbar \\&\;\;\vdots \end{aligned} }$$}@} Now {@{the Hamiltonian only has positive energy levels}@} as can be seen from {@{$${\begin{aligned}\langle \psi |2\mu H_{l}|\psi \rangle &=\langle \psi |C_{l}^{*}C_{l}|\psi \rangle +\langle \psi |(2l+3)\mu \omega \hbar |\psi \rangle \\&=\langle C_{l}\psi |C_{l}\psi \rangle +(2l+3)\mu \omega \hbar \langle \psi |\psi \rangle \\&\geq 0.\end{aligned} }$$}@} This means that for {@{some value of $l$ the series must terminate with $C_{l_{\text{max} } }|nl_{\text{max} }\rangle =0$}@}, and then {@{$$E_{l_{\text{max} } }^{n}=-{\frac {F_{l_{\text{max} } } }{2\mu } }=\left(l_{\text{max} }+{\frac {3}{2} }\right)\omega \hbar .$$}@} (annotation: Applying the upper boundary condition $C_{l_{\max} } \vert{}n l_{\max}\rangle = 0$ to the factorization identity $C_l^* C_l = 2\mu H_l + F_l$ gives $C_{l_{\max} }^* C_{l_{\max} } \vert{}n l_{\max}\rangle = (2\mu H_{l_{\max} } + F_{l_{\max} })\vert{}n l_{\max}\rangle = 0$.
