# surjective function

In {@{[mathematics](mathematics.md)}@}, {@{an __surjective function__, also known as __surjection__ or __onto function__}@}, is {@{a [function](function.md) $f$}@} such that, for {@{every element $y$ in its [codomain](codomain.md), there exists _at least_ one element $x$ that maps to $y$ in its [domain](domain%20of%20a%20function.md)}@}, i.e. {@{for a function $f : X \to Y$, $(\forall y \in Y)(\exists x \in X)(f(x) = y)$}@}.
