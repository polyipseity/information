# language model access

## the five routes

There are five routes to a model in Hong Kong, and each one has a cost.

| Route | Pro | Con |
| --- | --- | --- |
| Local LLMs | No extra cost | Weaker intelligence; Qwen, Gemma |
| China models | Cheap and stable | Not as powerful as Claude and GPT |
| Third-party API proxies | Very cheap | Unstable and insecure; PinCC |
| VPNs | Native Codex and Claude plans | Need an overseas credit card; risk of a ban |
| GitHub Copilot | Free for students, stable and safe | Usage limited on the free plan |

Not all of those costs are about price. Two routes buy cheap access with weaker models, and one needs a credit card you may not be able to get here. Both columns were true in September 2026, and the pricing and the access rules behind them move.

---

Flashcards for this section are as follows:

- the five routes: what does each one cost, and is any of that a price? ::@:: Intelligence, stability, access or usage limits, and none of them is a price
- which route gives native Codex and Claude plans, and what does that route cost? ::@:: A VPN: an overseas credit card you may not be able to get in Hong Kong, and a risk of a ban.
- which two routes buy cheap access with weaker models? ::@:: Local LLMs, such as Qwen and Gemma, and the China models, which are cheap and stable but not as powerful as Claude and GPT.
- what does GitHub Copilot cost a student, and what limits it? ::@:: Nothing, and it is stable and safe, but usage is limited on the free plan.
- when were the pros and cons in this table true, and what changes? ::@:: September 2026. The pricing and the access rules behind them move.

## GitHub and the Student Developer Pack

GitHub stores, shares and collaborates on software projects, and it is where the commits made while [vibe coding](vibe%20coding.md) end up. Real-world tools are cost-prohibitive for most students, so GitHub built the GitHub Student Developer Pack with partners and friends to give them hands-on experience. It puts tools that would otherwise cost money within reach.

---

Flashcards for this section are as follows:

- what does GitHub provide for a software project? ::@:: Git integration, collaboration tools, and an open source community
- who is the Student Developer Pack for, and what is it for? ::@:: Students, because the tools real software work needs cost too much for them
