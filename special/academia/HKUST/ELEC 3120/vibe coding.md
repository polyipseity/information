# vibe coding

Vibe coding is steering an agent in natural language instead of writing the code yourself. The steering splits into three parts.

1. __Defining intent.__ What you want built, and why.
2. __Structuring work.__ How it breaks into pieces an agent can take one at a time.
3. __Coordinating and review.__ Keeping it moving, and checking what comes back.

---

- vibe coding: what are the three parts of the human's job? ::@:: Defining intent, structuring work, and coordinating and reviewing

## git as a safety net

Git was built for collaborating with other humans. An agent writing your code gives it a second job: a safety net against AI mistakes. An agent writes fast, and it breaks things. The answer to both is to commit often.

---

Flashcards for this section are as follows:

- an agent writes fast and breaks things: what does that make necessary? ::@:: Commit often
