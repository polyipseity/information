# mnemonic

There is no photographic memory. A five-year search for people with such a memory found no one who came close and no credible evidence that one exists. Championship feats rest on technique and effort, which anyone can learn.

Mnemonic systems include the peg word technique and the memory palaces.

Looking for meaning improves memory for the material: a champion chess player given five seconds to look at a board set as in a match reproduced the positions almost perfectly over two minutes, and could hardly remember a board whose pieces were placed at random. A matrix of digits was encoded as sequences that meant something to its reader, and reading it back diagonally took longer than reading it in order, because there was no picture to scan, only the codes.

Flashcards for this section are as follows:

- whether a photographic memory exists ::@:: No. A five-year search found no individual with a truly photographic memory and no credible evidence that one exists.
- why a chess champion reproduces a game position but not a random arrangement ::@:: The game position carries meaning the champion can build on, while the random arrangement carries none, and material is remembered through its meaning.
- why a digit matrix takes longer to read back diagonally than in order ::@:: The digits were encoded as meaningful sequences rather than a picture, so the diagonal path breaks the sequences.

## memory palaces

The memory palace, or the method of loci, turns a familiar route into a filing system: fix a path through a place you know, turn each item into a vivid image, set one image at each stop, and walk the path to recall. It works because places outlast lists, a picture encodes more deeply than a word, and the route supplies stable cues in a fixed order. One championship system codes a deck this way: the six of hearts takes the code word hash, h for the suit and sh for the number, and the code words are woven into a story that carries the deck's order.

Flashcards for this section are as follows:

- how a memory palace is built ::@:: Fix a familiar route, turn each item into a vivid image, place one image at each stop, and walk the route to recall.
- why a memory palace works ::@:: Places outlast lists, images encode more deeply than words, and the route supplies stable cues in a fixed order.
- how the six of hearts is coded in a card-story system ::@:: The code word hash: h for the suit of hearts, sh for the number six, with each card's code word woven into a story.
