# encoding specificity principle

The encoding specificity principle is that the effectiveness of retrieval cues depends on the extent a retrieval cue matches the memory trace of an experience. Context-dependent memory shows the matching at work: studying in the same classroom as the exam puts the encoding context back in place at retrieval.

---

Flashcards for this section are as follows:

- the encoding specificity principle ::@:: A retrieval cue works when it matches the memory trace of the experience.
- how studying in the exam room shows encoding specificity ::@:: The room matches the context recorded there during study. The cue then matches the memory trace.

## state-dependent memory

State-dependent memory does the same from inside the person: memory is better when internal states match.

---

Flashcards for this section are as follows:

- what state-dependent memory adds to encoding specificity ::@:: Memory is better when the state at retrieval matches the state at encoding.

## cue overload

The cue overload principle sets the other limit: a retrieval cue cannot be overloaded with too many memories.

---

Flashcards for this section are as follows:

- the cue overload principle ::@:: A cue bound to too many memories retrieves none of them. Overload breaks the match.
