# mood-congruent memory

Mood-congruent memory is the tendency to recall memories whose valence matches the current mood (Bower, 1981). A sad person recalls a dog's death more easily than the dog's arrival. The mood at encoding stays with the memory, so the current mood is a retrieval cue.
