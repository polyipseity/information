# memory

Memory is the ability to keep information over time and bring it back when it is needed. One early account treats it as information processing with a limited capacity: Miller (1956) proposed the magic number 7, and phone numbers typically carry seven or eight digits within that capacity. Remembering runs through three stages, encoding, storage, and retrieval, and the three stages affect one another.

### working memory

Working memory is the ability to hold information in mind for a brief time and work with it. Doing math in your head and telling a story both draw on it. Its limits raise two questions: how much a person can hold, and how much a person can focus and resist interference.

### episodic memory

Episodic memory is the ability to remember the episodes of one's life. Autobiographical memory covers the specific events that have happened over the course of one's entire life. Strong emotion marks an event as worth encoding, so an emotional event stays vivid long after an ordinary one fades. The confidence it brings outruns its accuracy: the exact time, place, and words still fade.

### recoding

Encoding involves recoding, taking information from one form and converting it in a way that makes sense to us. Recoding can happen without awareness, as when new material associates with old memories. The recoding strategies are acronyms and associations, elaboration, and creating imagery. The acronym strategy turns the Big five personality traits into OCEAN: Openness, Conscientiousness, Extroversion, Agreeableness, and Neuroticism. Elaboration can improve encoding too, for instance when meeting a new person.

## storage

An experience leaves a memory trace, also called an engram, the change in the nervous system that represents the experience. Consolidation is the neural changes that occur over time to create the memory trace of an experience. Learning and testing are separated by the retention interval. Learning starts the interval and testing ends it. Consolidation works across it, while [retroactive and proactive interferences](interference%20theory.md) and the [misinformation effect](misinformation%20effect.md) act within it. Retrieval does not replay a past event. A retrieved event is reconstructed from memory traces and from current belief about what happened, and the reconstruction alters the representation held in storage.

## retrieval

Retrieval is accessing stored information when it is needed, and most of our memories will never be used without retrieval cues. Available memory is all information stored in memory. Accessible memory is the information a person is able to retrieve.
