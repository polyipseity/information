# lecture

- HKUST SOSC 1960 week 6 lecture 1
- parent: [week 6 lecture 1](index.md)

Memory covers the kinds it comes in and what makes recall succeed or fail. Working memory holds a few digits until they are written down. Collective memory is shared by a group. Semantic memory holds facts without their setting, and episodic memory holds events with their setting. Flashbulb memory keeps a shocking moment vivid. Retroactive interference is new learning that disrupts the old. False recognition recalls a word a list never held. Distinctiveness makes an unusual event stick in memory. Memory can fail at any stage. A retrieval cue brings a memory back.

- the new learning that disrupts the old ::@:: Retroactive interference.
